Preguntas frecuentes

¿Cuál es el tiempo de entrega de un sitio web?

Depende del paquete contratado: los sitios sencillos requieren pocos días y los sistemas de citas un plazo mayor. Tu cotización incluye la fecha de entrega comprometida.

¿Qué información necesito proporcionar para iniciar?

El nombre y el logotipo de tu negocio (si cuentas con uno), los textos o la información para redactarlos en conjunto, fotografías y tus datos de contacto. Te acompaño durante todo el proceso.

¿Cómo se realiza el pago?

50% de anticipo para iniciar el proyecto y 50% contra entrega, con el sitio ya publicado. El método de pago se acuerda en la cotización.

¿Puedo solicitar cambios una vez entregado el sitio?

Sí. Cada paquete incluye rondas de ajustes durante el desarrollo, y posteriormente puedes contratar el mantenimiento mensual para actualizaciones continuas.
